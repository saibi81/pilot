# 견적서 자동 생성 시스템 — PRD 요약

**에픽:** [UFTR-1](https://csi-vision.atlassian.net/browse/UFTR-1)  
**버전:** MVP 1.0  
**범위:** 로컬 브라우저에서 실행되는 정적 HTML/CSS/JavaScript 견적서 작성기

## 필수 요구사항

1. **FR-001 / UFTR-2:** 공급자 상호, 사업자번호, 대표자, 주소, 업태, 종목, 연락처와 이미지 직인 관리.
2. **FR-002 / UFTR-3:** 발행일, 수신처, 담당자, 견적번호, 유효기간 입력.
3. **FR-003 / UFTR-4:** 품목 추가·삭제·순서 변경, 여러 줄 규격, 월정액/일반수량/정액 계산 유형.
4. **FR-004 / UFTR-5:** 원 단위 정수 계산, VAT 포함·별도·면세, 한글 금액. VAT 포함값에 중복 VAT 가산 금지.
5. **FR-005 / UFTR-6:** 실시간 미리보기와 입력 상태 일치.
6. **FR-006 / UFTR-7:** A4 PDF 및 인쇄, 직인과 한글/원화기호 포함, 장문·복수 페이지 잘림 방지.
7. **FR-007 / UFTR-8:** 납품·계약조건, 여러 줄 비고 입력.
8. **FR-008 / UFTR-9:** 로컬 자동 저장, JSON 가져오기/내보내기, 초기화 및 오류 처리.

## 기준 검증 데이터

| 품목 | 계산 | 금액 |
| --- | --- | ---: |
| 생성형 AI 라이선스 | 44,000 × 12 × 5 | 2,640,000원 |
| 통합 관리 기능 | 정액 | 110,000원 |
| **합계** | VAT 포함 | **2,750,000원** |

한글 금액: **일금 이백칠십오만원정**

## 인수 조건

- 8개 FR의 기능·오류처리·데이터 저장 동작 충족
- 계산 및 JSON 검증에 대한 자동 테스트 통과
- Chrome/Edge 수동 인쇄/PDF 점검
- 기본 견적서 1페이지, 긴 문서는 페이지 분리 및 직인/폰트 이상 없음 확인
- 사용자 설명서 확인 후 비개발자도 견적서 생성 가능

## 개발 범위 외

복수 사용자 로그인, 서버 데이터베이스, 견적 이력 목록, 승인, 이메일 발송, AI 품목 추천 기능은 추후 개발 범위입니다.
